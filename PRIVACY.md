# Privacy Policy — GroupNap

**Last updated:** May 15, 2026

## Data Collection

This extension **does not collect, transmit, or share any user data**. Period.

Usage statistics (tabs napped, groups collapsed) are stored **locally on your device** using `chrome.storage.local`. This data never leaves your browser and can be reset anytime from the extension popup.

## Permissions

| Permission | Purpose |
|------------|---------|
| `tabGroups` | Detect when a tab group is collapsed or expanded |
| `tabs` | Read tab state (active, pinned, audible, discarded) and discard inactive tabs |
| `storage` | Store usage statistics locally on your device |

These permissions are used **exclusively for local tab management** within your browser. No information about your tabs, browsing history, or URLs ever leaves your device.

## Network Requests

This extension makes **zero network requests**. It does not communicate with any server, API, or external service.

## Analytics & Tracking

None. No analytics, no telemetry, no tracking pixels, no third-party scripts.

## Remote Code

This extension does not load or execute any remote code. All functionality is contained in the locally installed extension files.

## Third-Party Services

None.

## Changes to This Policy

Any changes will be reflected in this file and the extension's store listing. The "Last updated" date above will be revised accordingly.
